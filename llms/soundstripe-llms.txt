- [Upload an asset](https://docs.soundstripe.com/reference/upload-an-asset.md): Upload a single image or video that can be referenced from a later search. Processing is asynchronous; the response is 202 and the asset's lifecycle (`pending` → `processing` → `processed`, or a terminal failure) is then driven by Soundstripe.
- [Retrieve an asset](https://docs.soundstripe.com/reference/retrieve-an-asset.md): Retrieve the processing state of a previously uploaded asset. Assets are scoped to the requesting API key; references from other keys look like 404.
- [Webhooks](https://docs.soundstripe.com/reference/webhooks.md): Receive search results via signed webhook delivery.
